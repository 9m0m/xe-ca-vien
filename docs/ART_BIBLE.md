# Xe Cá Viên — Art Bible

## Direction

2D hand-drawn game illustration, warm and clean, slightly stylized but clearly recognizable as real street food. Slight elevated three-quarter/top-down perspective. Strong silhouettes for small mobile presentation.

## Consistency

Every food asset:

- same perspective family
- same light direction
- same outline/edge treatment
- similar object scale
- transparent background
- no text
- no watermark
- no decorative unrelated props

Food should have natural small imperfections. Avoid perfect glossy spheres.

## UI

Never use emoji as production icons.
Use one consistent SVG icon family/custom set.
UI text must be real rendered text, never text baked into generated art.

## Southern Vietnamese street-food cues

Use ordinary practical objects:

- inox cart and trays
- frying pan
- metal tongs
- bamboo skewers
- squeeze sauce bottles
- plastic baskets
- small stools
- simple menu-board framing

Avoid cliché tourist symbolism unless it genuinely belongs in the scene.

## FX

Frying oil is a composition:

- pan/oil base
- bubble particles
- splash sprites
- subtle steam
- food sprite animation
- sound

Do not create one giant baked image containing all frying effects.

## Forbidden visual patterns

- emoji-like assets
- random 3D/Pixar look
- hyper-real food photography
- casino/mobile-ad gloss
- neon/cyberpunk
- purple-blue AI gradients
- excessive bloom
- random sparkles
- inconsistent camera angles
- generated Vietnamese lettering inside images
- glassmorphism as dominant game UI
- generic SaaS dashboard visuals

## Asset production order

1. gameplay placeholders
2. canonical fish ball test asset
3. canonical beef/shrimp/tofu/sausage/dumpling tests
4. phone-size silhouette review
5. lock style
6. batch production by shape family
7. atlas/export optimization

Consistency outranks detail.
